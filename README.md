# ST Rugby Drill Viewer

A one-screen drill viewer for players. Find a drill, watch it, and line drills up in a playlist to follow a script. Nothing to build.

- Portrait: video on top, then a Drills / Playlist switch.
- Landscape and wide screens: playlist, video and drill list side by side.
- Playlist: + to add or remove, up and down arrows to reorder, Clear, Play in order, Copy link (opens the same playlist for someone else). Saved on the device.
- Add to home screen for the app icon (marked VIEWER).

The page is password protected (staticrypt). The source is generated from the main drill visualiser, so changes are made there and this repo is republished.
